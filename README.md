## 🌟 Core Philosophy: The Reality vs. RPG Divide

Fitness and habit tracking apps often lose users after the first month through **loss aversion**, **binary streak resets**, and the psychological **"What-the-Hell" effect**. A single missed day resets a counter to zero, causing users to abandon the habit entirely.

**Ascend Core addresses this through architectural separation:**
1. **The Reality Layer (Real Life):** Real-world habits, compound gym lifts, deep work sessions, and sleep quality serve as the **training grounds** where player attributes are forged.
2. **The RPG Layer (The Tower & Gauntlets):** The simulated game world where stats are put to the test. You never defeat monsters by merely checking off a box—you conquer dungeons using the tangible power earned through real-world discipline.
3. **Forgiving Habit Progress:** Pairs streaks with a **habit strength score** and automated **Streak Freeze Shields**, so one missed day reduces momentum instead of erasing it.

## ⚡ Key Features & Sidebar Subsystems

Ascend Core organizes all user operations, disciplines, combat trials, economy, and system intelligence across **19 specialized sidebar subsystems**:

### 📁 // OPERATIONS (Core & Daily Ops)

#### 🖥️ 01. Dashboard (`/dashboard`)
* **Hunter Identity & Telemetry:** Real-time HUD tracking **Level**, **Class Archetype**, **Hunter Rank** (F-Rank through SSS-Rank), **Power Score**, and **HP/EXP** progression.
* **Dual Currency Indicators:** Persistent tracking for soft currency (**Gold**) and premium currency (**Gems / Ascension Crystals**).
* **7-Attribute Radar Visualization:** Recharts-powered interactive radar measuring real-time equilibrium across **Strength**, **Knowledge**, **Discipline**, **Focus**, **Endurance**, **Recovery**, and **Consistency**.
* **Quick-Action Fast Logging:** Instant logging for daily habits, active quests, and step telemetry directly from the overview dashboard.

#### 🎯 02. Missions & Quest Log (`/missions`)
* **Kanban Quest Board:** Move missions across *To Do*, *In Progress*, *Review*, and *Completed* columns with status controls.
* **Ranked Quest Rewards:** Kanban quests award EXP, gold, and stat points by rank, from F-Rank (+50 EXP, +15 Gold) to S-Rank (+500 EXP, +150 Gold).
* **Multi-Step Subtask Checklists:** Create rich missions with sub-checklists; checking off subtasks updates progress bars dynamically.

#### 🔁 03. Habit Mastery & Heatmap (`/habits`)
* **Habit Strength Score:** Blends consistency (40%), success rate (35%), and completion quality (25%), with smoothing and partial decay on missed days.
* **3-Tier Completion Rewards:** Complete a habit at **Mini** (40%), **Normal** (100%), or **Elite** (170%) reward levels to maintain momentum on low-energy days.
* **GitHub-Style 365-Day Heatmap:** Visualizes daily execution density across all 365 days of the year.
* **Streak Freeze Shields:** Consumable shields that auto-deploy on missed days to preserve accumulated multipliers.

#### 📅 04. Unified Schedule Calendar (`/calendar`)
* **Unified Visual Timeline:** Combines scheduled habits, planned workout splits, and mission due dates into a single cohesive monthly/weekly view.
* **Historical Density Badges:** Inspect past completion records, logged workouts, and sleep quality scores for any date.

---

### 🏋️ // DISCIPLINES (Character & Disciplines)

#### 👤 05. Hunter Profile & Credentials (`/profile`)
* **Hunter License & Status Bar:** View official hunter rank credentials, lifetime statistics, and progression history.
* **Stat Allocation Matrix:** Spend unallocated stat points directly into STR, KNW, REC, DIS, END, FCS, and CON.
* **Equippable Milestone Titles:** Equip unlocked titles (*"Brawler"*, *"Scholar"*, *"God of War"*) that grant stat bonuses and power multipliers.

#### 🦾 06. Workouts & 16-Muscle Heatmap (`/workouts`)
* **Active Gym Session Logger:** Log exercises, weights, reps, and **RPE**.
* **16-Muscle Anatomical Heatmap:** Interactive vector model with per-muscle **time-decay recovery** (48h or 72h depending on the muscle).
* **Estimated 1RM:** Calculates estimated one-rep max using the **Brzycki** and **Epley** formulas.
* **Progressive Overload Suggestions:** Suggests **+2.5 kg** on compound lifts, or **+5%** on isolation lifts, once the rep target is met.

#### 😴 07. Sleep & Rest Telemetry (`/sleep`)
* **Sleep Logger:** Track sleep duration and rest quality across five tiers, from *Poor* to *Deep REM*.
* **Circadian Efficiency Curve:** Computes recovery efficiency against an 8-hour optimal baseline.
* **Recovery (REC) Stat Scaling:** Logged sleep awards EXP and a **Recovery** bonus based on sleep quality.

#### 🧠 08. Learning Sanctuary & Ambient Audio (`/learning`)
* **Pomodoro Deep Work Timer:** Configurable flow-state intervals (25m Focus / 5m Break / Custom) rewarding **Knowledge** and **Focus** attributes.
* **Cyber Rain Ambient Sound Player:** Built-in audio player with a looping rain track.
* **Generative Ambient Tones:** Uses the Web Audio API to generate a layered 528 Hz focus tone.

#### 🌌 09. Skill Constellations & Specializations (`/skills`)
* **Branching Class Skill Trees:** Constellation trees across classes including *Novice Warrior*, *Apprentice Mage*, *Assassin*, *Paladin*, and *Shadow Monarch*.
* **Skill Points (SP):** Earn SP upon leveling up and invest it into skills.
* **Interactive Node Modal:** Inspect skill details and unlock prerequisites.

---

### ⚔️ // COMBAT (Conquest & Trials)

#### 🏰 10. Tower of Ascension (`/tower`)
* **20-Floor Tactical Gauntlet:** Battle through 20 floors that test your real-world progress.
* **Turn-Based Auto-Combat Simulator:** Resolves battles using your **Strength**, **Knowledge**, **Focus**, **Endurance**, and **Recovery** stats plus equipped gear.
* **AIRA Defeat Diagnosis:** In-depth tactical autopsy report upon defeat explaining exact failure points and recommending specific attributes to train.

#### 👹 11. World Bosses & Reality Raids (`/bosses`)
* **Multi-Month Life Raids:** Transform monumental real-world goals (*"Defend Master's Thesis"*, *"Run a Marathon"*) into multi-phase raid bosses.
* **Habit-to-Boss Linking:** Checking off linked daily habits in real life deals direct damage to the boss's HP pool.
* **Boss Phases:** Each boss moves through 4 phases as HP depletes.

#### 🏆 12. Boss PR Breakthrough Arena (`/workouts/boss-pr`)
* **Personal Record Boss Encounters:** Your top PR exercise becomes a weekly boss target at 90% of its weight, with Barbell Bench Press as the fallback.
* **Breakthrough Damage:** Achieving a new 1RM deals massive critical damage, triggering celebratory confetti and high-tier loot.

---

### 🎒 // ARMORY (Armory & Economy)

#### 🎒 13. Inventory & 9-Slot PaperDoll (`/inventory`)
* **Interactive 9-Slot PaperDoll:** Visual gear matrix (`WEAPON`, `HELMET`, `ARMOR`, `GLOVES`, `BOOTS`, `RING`, `NECKLACE`, `ARTIFACT`, `RELIC`).
* **Deep Item Lore & Modifiers:** Rich tooltips detailing item lore, equip requirements, and active stat modifiers.
* **Rarity Hierarchy:** `COMMON` $\rightarrow$ `RARE` $\rightarrow$ `EPIC` $\rightarrow$ `LEGENDARY` $\rightarrow$ `MYTHIC`.

#### ⚒️ 14. Forge & Crafting (`/crafting`)
* **Blacksmith Crafting:** Forge gear from materials such as Shadow Steel Ingots and Dragon Drake Scales.
* **Live Recipe Tracking:** Recipes show required ingredients against your current inventory.

#### 🏪 15. Merchant Shop & Economy (`/shop`)
* **Rotating Market:** Browse refreshable stock with limits by item rarity, plus free daily refresh charges.
* **Dual Currency Balance:** Spend gold and gems on shop items and upgrades.

#### 🐉 16. Beast Incubation & 20 Dragons (`/beasts`)
* **Step Incubation:** Real-world walking steps incubate mystery elemental beast eggs.
* **20 Unique Dragon Species:** Complete catalog of animated elemental dragons (`beast_1.gif` to `beast_20.gif`) spanning 7 elemental affinities (**Void**, **Nature**, **Frost**, **Fire**, **Cyber**, **Holy**, **Storm**).
* **Companion Leveling:** Feed accumulated steps and gold to level companions up to Level 10, scaling their passive buffs.

---

### ⚙️ // SYSTEM CORE (System Core & Intelligence)

#### 🤖 17. AI System / AIRA (`/aira`)
* **Clinical System Persona:** Unemotional, data-driven AI advisor inspired by *Solo Leveling's System* and *Ciel / Raphael*.
* **Proactive Contextual Notifications:** Real-time toast notifications (`useAiraNotification.ts`) delivering circadian briefings, midnight decay warnings, and anatomical readiness alerts.
* **Mutative Tool Calling:** Autonomously generates customized workout routines, creates habit schedules, and logs completed quests directly via the **Google Gemini API**.

#### 🎖️ 18. Milestone Achievements Codex (`/achievements`)
* **Structured Milestone Trophies:** Track progress across Habits, Workouts, Tower, and Social categories.
* **Account Perks:** Unlocks gems, exclusive hunter titles, and permanent account multipliers.

#### ⚙️ 19. Automations Engine (`/automations`)
* **Event-Driven Rules Engine:** Configure rules that react to phone usage, drowsiness, and posture signals by triggering a linked negative habit.
* **Daily System Surges:** The Habits page also offers daily bonuses including **5x Habit 2x Boosts**, **1x Learning 2x Boost**, **1x Workout 2x Surge**, and **Free Daily Egg Claims**.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/RIll-cmd/ascend-core.git
cd ascend-core
```

---

### 2. Backend Setup (`server/`)

```bash
# 1. Navigate to the backend directory
cd server

# 2. Create and activate a Python virtual environment
python -m venv venv

# Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# macOS / Linux:
source venv/bin/activate

# 3. Install Python dependencies
pip install -r requirements.txt

# 4. Configure environment variables
cp .env.example .env

# 5. Push database schema and generate Prisma client
prisma db push
prisma generate

# 6. Start the FastAPI development server
python main.py
```
> ⚡ *The FastAPI server will start on `http://localhost:8000`.*
> 📖 *Interactive Swagger API documentation is available at `http://localhost:8000/docs`.*

---

### 3. Frontend Setup (`client/`)

Open a new terminal tab/window:

```bash
# 1. Navigate to the client directory
cd client

# 2. Install dependencies
npm install

# 3. Configure environment variables
cp .env.example .env.local

# 4. Start the Next.js development server
npm run dev
```
> 🌐 *The web application will be accessible at `http://localhost:3000`.*

## 🔐 Environment Variables

### Backend Configuration (`server/.env`)
| Variable | Required | Default | Description |
| :--- | :---: | :---: | :--- |
| `DATABASE_URL` | **Yes** | None | PostgreSQL connection string |
| `DATABASE_URL_UNPOOLED` | **Yes** | None | Direct non-pooling URL for migrations (e.g., Neon direct) |
| `SECRET_KEY` | Production | Development-only value | Secret key used to sign and verify JWT authentication tokens |
| `CRON_SECRET` | Production | None | Bearer token that authorizes `/api/cron/*` requests |
| `GEMINI_API_KEY` | Optional | None | Google Gemini API key for AIRA AI analysis & tool calling |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` | Optional | Port `587` | SMTP connection used to send email verification codes |
| `SMTP_FROM_EMAIL`, `SMTP_FROM_NAME` | Optional | Built-in sender | Sender details for verification emails |
| `INTEGRATION_API_KEY` | Optional | None | Secret key for Ascend Vision and background integrations |
| `GUEST_ACCESS_PASSWORD` | Optional | None | Password for guest access; guest login is disabled when unset |
| `FRONTEND_URL` | Production | None | Allowed frontend origin for CORS |

### Frontend Configuration (`client/.env.local`)
| Variable | Required | Default | Description |
| :--- | :---: | :---: | :--- |
| `NEXT_PUBLIC_API_URL` | Local development | `http://127.0.0.1:8000` | Backend API base URL; leave blank on Vercel to use same-origin rewrites |
| `NEXT_PUBLIC_APP_URL` | Optional | `http://localhost:3000` | Client URL for share links, redirects, and meta tags |

## 🚢 Deployment

### Production Architecture (Vercel, Render & Neon)
1. **Frontend (Vercel):** The Next.js app in `client/` is hosted on Vercel in region `sin1` (Singapore).
2. **Backend (Render):** The FastAPI app in `server/` runs on Render. `vercel.json` rewrites `/api` requests to the Render service.
3. **Database (Neon PostgreSQL):** Persistent data is stored in Neon Serverless PostgreSQL with connection pooling (`-pooler`).
4. **Automated Crons:** Vercel Cron Jobs (`vercel.json`) call `/api/cron/status-sweep` and `/api/cron/midnight-decay`, guarded by `CRON_SECRET`.

#### Deployment Steps:
1. Push the repository to GitHub.
2. Create a [Render](https://render.com) web service for the backend and configure its environment variables:
   - `DATABASE_URL` (Neon pooled endpoint: `postgresql://...-pooler.../neondb?sslmode=require`)
   - `DATABASE_URL_UNPOOLED` (Neon direct endpoint)
   - `SECRET_KEY` (JWT signing secret)
   - `CRON_SECRET` (Secure token for cron authorization)
   - `FRONTEND_URL` (Deployed frontend origin)
   - `GEMINI_API_KEY` (AIRA AI integration)
3. Update the rewrite destinations in `vercel.json` to your Render URL.
4. Import the project into [Vercel](https://vercel.com) and set the Root Directory to `./` with the **Next.js** preset.
   Keep the install and build commands from `vercel.json`: install with `npm ci --include=dev && npm ci --prefix client --include=dev`, then build with `npm run build`. Leave Output Directory at the Next.js default. The first install makes Next.js resolvable from the project root; the second installs the frontend's locked dependencies. Commit both the root `package-lock.json` and `client/package-lock.json`. Installing only with `--prefix client` causes Vercel's root-level Next.js version detection to fail even when `next` is declared in the root manifest. Do not change Root Directory to `client`, as this deployment also uses the root cron configuration.
5. Set `CRON_SECRET` in the Vercel Dashboard to the same value used on Render, then deploy.
